# 远距离织纹采样修复

## 定位

- 本地 Three.js r170 使用 WebGL 2，普通 TextureLoader 默认已有 Mipmap 和三线性过滤。原业务代码未统一指定这些参数：FBX 克隆继承输入设置，项目图案恢复未设置各向异性，其他上传路径将各向异性上限固定为 8。
- 原法线始终按 normalScale 扰动，凹凸始终按 bumpScale 差分；织纹缩小后，过滤结果再归一化或差分仍可能造成远景明暗波动。单纯提高各向异性无法消除这类波动。

## 修改

- 所有图像贴图入口统一启用 generateMipmaps、LinearMipmapLinearFilter、LinearFilter，以及设备支持的最大各向异性（不支持时为 1）。保留源图尺寸，包括非 2 次幂图片，保留颜色/数据贴图各自的色彩空间。
- 法线和凹凸使用各自变换后的 UV 导数及 GPU 上实际贴图尺寸计算纹素覆盖率。在每像素不超过 1 纹素时保持原强度；在 1–8 纹素之间按 mip 层级平滑衰减，达到 8 纹素后回到几何法线。
- 凹凸三次高度采样统一使用 textureGrad 的同一对梯度，再衰减高度差，避免偏移采样之间选择不同 Mipmap。
- 采样着色器与粗糙度灰度/反转共用安装入口，覆盖编辑器、FBX、库材质、项目恢复、图案以及克隆/替换动画。原图、normalScale、bumpScale、UV 和物理尺寸不被衰减逻辑改写。

## 验证

先启动本地服务，再运行 `node checks/texture-sampling.test.cjs`（也可使用 `npm run test:sampling`）。默认使用本地 Edge 和 4186 端口，可通过 FORM_BASE_URL、PLAYWRIGHT_PATH、BROWSER_CHANNEL 指定环境。

2026-09-20：

- `node --test checks/*.test.mjs`：27 项通过。
- 新增 WebGL 实际渲染测试：非 2 次幂织纹、切线/物体空间法线、凹凸、UV2、斜视角、粗糙度转换、两种揭示动画均通过，无 GL 错误。
- 测试织纹近景与原渲染的平均像素差为 0；中远景相对无凹凸平面的明暗偏差减少约 71%–78%，轻微平移导致的变化减少约 70%–73%；覆盖率超过 8 纹素后细节差为 0。这是合成测试的指标，并非对所有素材作相同比例保证。
- 编辑器上传/保存/重开、FBX 原贴图、实际拖拽换材质、项目保存/恢复均通过；四张测试贴图保持原始 126×98 分辨率、UV2 和正确色彩空间。
- 旧 `entry-workflow.test.cjs` 在“底栏应显示全部 10 个材质”的断言失败。当前源码 `renderMaterials()` 已按分类过滤，选中测试面料时只显示该分类的 1 个材质。新增测试读取实际材质集合，确认总数仍为 10，并完成替换和项目恢复验证。

本方案对远景法线/凹凸整体衰减，适用于细织纹；如果未来需要远处保留同一贴图中的大尺度褶皱，应将宏观褶皱与微观织纹分层处理。
