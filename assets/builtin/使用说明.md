# 添加内置素材

1. 把 `.formmat` 文件复制到本目录，文件名就是素材库里显示的名称。
2. 双击项目根目录的 `更新内置素材.bat`，看到成功提示后刷新网页。
3. 分享线上版本时，运行原来的 `更新网站.bat`，它也会自动更新清单后发布。

`启动编辑器.bat` 同样会先更新清单。更新程序使用 Windows 自带 PowerShell，无需安装 Node 或 Python。

图案/面料类型读取材质包内保存的设置；文件名包含“面布”“边布”“包边”“滚边”时会识别面料分类，其他名称沿用包内分类。刺绣素材应在材质编辑器中设为图案再导出。

同名文件不会重复添加；替换同名文件的内容后重新生成清单，刷新网页会同步新版本（包括覆盖该内置素材在浏览器内的本地编辑）。文件改名视为新增素材，建议保持名称稳定。移走文件会使其不再提供给新访客，已导入旧素材的浏览器仍保留旧副本。

清单 `manifest.json` 自动生成，不需要手动修改。四个原有示例保留原来的资产 ID。无效材质包会报出文件名并停止，保留上一份清单。

发布时一并上传本目录中的素材文件和清单，以及更新后的 `shared/asset-store.js`。更新清单本身不会上传网站。
