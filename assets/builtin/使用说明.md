# 添加内置素材

1. 把 `.formmat` 文件复制到本目录，文件名就是素材库里显示的名称。
2. 双击项目根目录的 `更新内置素材.bat`，看到成功提示后刷新网页。
3. 分享线上版本时，运行原来的 `更新网站.bat`，它也会自动更新清单后发布。

`启动编辑器.bat` 同样会先更新清单。更新程序使用 Windows 自带 PowerShell，无需安装 Node 或 Python。

图案/面料类型读取材质包内保存的设置；文件名包含“面布”“边布”“包边”“滚边”时会识别面料分类，其他名称沿用包内分类。刺绣素材应在材质编辑器中设为图案再导出。

同名文件不会重复添加；替换同名文件的内容后重新生成清单，刷新网页会同步新版本（包括覆盖该内置素材在浏览器内的本地编辑）。文件改名视为新增素材，建议保持名称稳定。移走文件会使其不再提供给新访客，已导入旧素材的浏览器仍保留旧副本。

清单 `manifest.json` 自动生成，不需要手动修改。四个原有示例保留原来的资产 ID。无效材质包会报出文件名并停止，保留上一份清单。

更新清单时会读取包内已经保存的预览图，并导出到 `previews` 子目录，供卡片单独加载。未保存预览图的旧材质显示“无预览图”；在材质编辑器中生成预览并重新导出后，再替换本目录中的包即可。

浏览资产库只读取清单和当前页的预览图。打开面料详情或添加到设计台时，读取 `runtime` 子目录中的独立材质参数和运行贴图，不下载完整包。保存到线上项目库只记录素材引用和设计清单；编辑、导出材质时才按需读取源材质包。

更新程序提前生成最长边不超过 2048 像素的运行贴图，并保留厘米尺寸、角度、偏移和材质参数。颜色 JPEG 使用 90% 质量；需要缩放的法线、粗糙度等数据图和透明图案使用 PNG。已经符合大小要求的 JPEG/PNG 直接保留原文件内容。如果 Windows 图像组件无法解码 WebP，会单独发布该 WebP，由浏览器首次使用时生成运行图。

源材质包不要移走；运行图用于显示和线上项目引用，源文件用于材质编辑与导出。运行图目录使用材质内容版本命名，重复更新会复用已生成文件；曾被线上项目引用的版本目录应保留。替换源包后请重新更新清单；使用旧版素材进行原文件导出时，若源包版本发生变化会提示重新添加。

上线时需一并上传素材包、清单、`runtime`、`previews` 子目录和项目代码。新清单要求每个内置材质都有运行配置地址，不兼容旧版仅引用整包的清单。`vercel.json` 已配置版本目录和预览图的长期缓存；更新清单本身不会上传网站。

## 模型素材

也可将 `.glb` 或 `.fbx` 放入本目录，更新工具会将它们登记为模型素材。配套纹理等文件放在与模型同名、追加 `.resources` 的目录，例如 `床垫.fbx.resources/`；资源使用原文件名，目录内不再嵌套子目录。可选预览图命名为 `床垫.fbx.preview.png`。

浏览列表只读取模型名称和预览图，进入设计或配置页面时才下载模型及配套文件；重复打开复用浏览器缓存。模型或配套资源内容改变后，更新清单会同步新的版本。模型使用现有 FBX/GLB 加载器，当前不自动转换模型格式，也不自动添加 Draco/Meshopt 几何压缩。
