# BMP → JPG 面料纹理原型

这是一个纯浏览器原型，不依赖后端或第三方库。推荐通过本地 HTTP 服务器打开：

1. 读取 BMP 并取出像素组织图。
2. 每一个 BMP 像素在同一物理格内上下生成两个线圈，两个线圈共享该像素的颜色。横向固定为 10 BMP 像素/cm，纵向默认 6 BMP 像素/cm；页面可编辑纵向 BMP 像素/cm（2376×600 px 在默认值下对应 237.6×100 cm）。输入 DPI 后，按 BMP 推导的物理尺寸换算 JPG 像素宽高；预览信息同时显示 cm、英寸、像素和 DPI，下载 JPG 的 JFIF 元数据也写入该 DPI。
   输出尺寸由物理尺寸和 DPI 决定，不再设置 4000 万像素上限或自动降低倍率。
3. 自动统计 BMP 实际使用的像素颜色，按数量排序生成色号，数量最多的颜色为 0 号色。
4. 右侧色号及背景色复用设计台属性栏的圆形色板与 HSV 取色器，材质编辑器中的取色器以悬浮窗形式锚定在当前色板旁，支持 HEX 输入，点击“确定”应用，Esc 放弃修改。凹陷勾选、原色与像素数量保留；修改某个色号会同步修改所有对应位置的线圈。
5. 用贝塞尔曲线构造饱满的线圈双腿、后方圈头和圆润底弯；纱线跨越相邻行，由表面深度决定穿套遮挡。色号只作用于实际纱线覆盖区域。可用“背景色”独立修改线圈间空隙的颜色，默认白色；整图、局部预览及导出的 JPG / PNG 同步使用所选背景。
6. 圆管截面法线、柔光与遮挡暗部呈现立体感；四次子像素采样减轻小针距的锯齿。白色采用乘法明暗，保留高光和阴影层次。
7. 优先使用 Web Worker 计算；直接打开 HTML 或后台线程启动失败时，自动切换为可取消的分批渲染，并显示进度，避免一直停留在“正在渲染”。整图和局部预览分别处理错误。
8. 点击面料全图，按每个 BMP 像素宽 28 像素、上下两个线圈独立重绘该位置的局部细节；可下载全图 JPG 或局部 PNG。选择“实际像素”可滚动查看全图原始分辨率。
9. 点击“生成贴图”会在一个任务中只计算一次浮点高度场，再派生白底荆棘高度图、OpenGL 切线空间法线图和 AO 图。调色板每行的“凹陷”复选框指定哪些色号的像素作为凹点。根据 Shape Thorn 参考图，使用四次方径向轮廓 `profile(t)=(1-t)^4`（t 为距离/半径，半径外为 0），反相为凹陷 `stamp=1-depth*profile`。各像素的 stamp 按正片叠底相乘，重叠区域共同加深。半径以 BMP 像素短边为单位，默认 5，最小 0.05，不设上限；凹陷深度默认 60%。高斯模糊以输出像素为单位控制 sigma，默认 0（关闭），在共用浮点高度场上只执行一次，三张图使用相同的模糊结果。法线从浮点高度场做有限差分，再编码 RGB，不读取量化或 JPG 压缩后的高度图；法线 RGB 使用 `R=X、G=+Y、B=+Z`，平坦区域为 `[128, 128, 255]`。
10. AO 沿 8 个方向、每方向最多 6 个距离采样周围高度，估算相对于局部切面的遮蔽；开阔平面为白色，凹陷受遮挡处变暗。AO 范围以 BMP 像素短边为单位，默认 5，随 DPI 换算；AO 强度默认 1，可设为 0–3。它表现当前宏观高度场的遮蔽，不包含纱线穿套的几何遮蔽。
11. 高度、法线、AO 与纹理统一导出 JPG，使用相同物理尺寸、DPI 换算出的像素宽高、JPG 质量和 JFIF 双轴 DPI 元数据；各图可独立预览和下载。三张派生图逐张编码及传递，避免同时保留三份原始 RGBA 输出。修改凹陷、模糊、AO、DPI 或 JPG 质量后，派生图下载失效，材质编辑器中的旧法线和 AO 也会移除。生成成功后，法线和 AO 自动应用到 `normalMap` 和 `aoMap`，使用线性颜色空间及相同的物理 UV，保存材质时一并保留贴图和生成参数。
12. 编辑器生成贴图时默认开启循环平铺采样（`tileable: true`）。高度场包含四边及四角相邻块的凹陷，高斯模糊、法线差分和 AO 越界采样均从对侧读取，等效于平铺扩边、处理后裁出中间块。输出宽高、物理尺寸和 DPI 不变，无须分配九倍大的高度场。底层渲染 API 未传 `tileable: true` 时保留原有非平铺边界；源图案本身的边界错位不由此修复。

在 `EBT` 根目录启动静态服务器后打开 `http://localhost:5173/web-demo/`，点击“选择 BMP”。

```powershell
node .\web-demo\server.mjs
```

也可以直接双击 `web-demo/index.html`，再点击“选择 BMP”读取本地图片。若浏览器限制本地文件读取，请改用上面的 HTTP 地址。

`knit-renderer.js` 负责周期纱线几何、着色、共用高度场、OpenGL 法线和 AO，`render-worker.js` 负责后台渲染，`render-task.js` 负责逐图传递、取消及分批回退，`app.js` 负责文件、调色板、预览、JPG 编码、DPI 写入及材质通道应用。点击“生成贴图”依次导出 `fabric-height-radial.jpg`、`fabric-normal-opengl.jpg` 和 `fabric-ao.jpg`。高度场、模糊、法线和 AO 阶段均支持进度与取消；分批回退也不再阻塞整个高度场或模糊阶段。

在 `web-demo` 目录运行 `node --test regression.test.cjs relief.test.cjs relief-maps.test.cjs` 可检查线程故障、直接打开文件、各阶段取消、单次高度场计算、分批渲染一致性、荆棘轮廓、正片叠底、AO、JPG 编码及 DPI。根目录运行 `node checks/procedural-relief.test.cjs` 检查真实 Worker、回退、三张图的尺寸/下载、AO 材质通道、参数失效、材质包保存和重新打开。

这是程序化的针织表面近似，尚未模拟真实纤维毛羽与纱线张力。全图默认每个 BMP 像素宽约 4 像素；观察上下双线圈的穿套与截面应使用独立重绘的局部视图。
