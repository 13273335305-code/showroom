# BMP → JPG 面料纹理原型

这是一个纯浏览器原型，不依赖后端或第三方库。推荐通过本地 HTTP 服务器打开：

1. 读取 BMP 并取出像素组织图。
2. 每一个 BMP 像素在同一物理格内上下生成两个线圈，两个线圈共享该像素的颜色。横向固定为 10 BMP 像素/cm，纵向默认 6 BMP 像素/cm；页面可编辑纵向 BMP 像素/cm（2376×600 px 在默认值下对应 237.6×100 cm）。输入 DPI 后，按 BMP 推导的物理尺寸换算 JPG 像素宽高；预览信息同时显示 cm、英寸、像素和 DPI，下载 JPG 的 JFIF 元数据也写入该 DPI。
   输出尺寸由物理尺寸和 DPI 决定，不再设置 4000 万像素上限或自动降低倍率。
3. 自动统计 BMP 实际使用的像素颜色，按数量排序生成色号，数量最多的颜色为 0 号色。
4. 右侧每个色号都有独立颜色框；修改某个色号会同步修改所有对应位置的线圈。
5. 用贝塞尔曲线构造饱满的线圈双腿、后方圈头和圆润底弯；纱线跨越相邻行，由表面深度决定穿套遮挡。色号只作用于实际纱线覆盖区域。可用“背景色”独立修改线圈间空隙的颜色，默认白色；整图、局部预览及导出的 JPG / PNG 同步使用所选背景。
6. 圆管截面法线、柔光、遮挡暗部与纤维微纹理呈现立体感；四次子像素采样减轻小针距的锯齿。白色采用乘法明暗，保留高光和阴影层次。
7. 优先使用 Web Worker 计算；直接打开 HTML 或后台线程启动失败时，自动切换为可取消的分批渲染，并显示进度，避免一直停留在“正在渲染”。整图和局部预览分别处理错误。
8. 点击面料全图，按每个 BMP 像素宽 28 像素、上下两个线圈独立重绘该位置的局部细节；可下载全图 JPG 或局部 PNG。选择“实际像素”可滚动查看全图原始分辨率。
9. 可按需生成白底荆棘高度图和 OpenGL 切线空间法线图。调色板每行的“凹陷”复选框指定哪些色号的像素作为凹点。根据提供的 Shape Thorn 参考图，使用四次方径向轮廓 `profile(t)=(1-t)^4`（t 为距离/半径，半径外为 0），反相为凹陷 `stamp=1-depth*profile`。各像素的 stamp 按正片叠底相乘，重叠区域共同加深。半径以 BMP 像素短边为单位，界面默认 1，最小 0.05，不设上限，输入 50 或更大值会按实际数值生成；深度由滑杆控制。法线图从同一浮点高度场做有限差分，再编码 RGB，不经过 JPG 压缩后的高度图。法线 RGB 使用 `R=X、G=+Y、B=+Z`，平坦区域为 `[128, 128, 255]`。
10. 高度图、法线图与纹理图统一导出 JPG，使用同一物理尺寸、DPI 换算出的像素宽高、JPG 质量和 JFIF 双轴 DPI 元数据。预览缩小仅影响页面显示，下载保留完整输出尺寸。修改 DPI 或 JPG 质量后，高度/法线下载会失效并提示重新生成，防止下载旧参数的图片。

在 `EBT` 根目录启动静态服务器后打开 `http://localhost:5173/web-demo/`，点击“加载案例 BMP”或“选择 BMP”。

```powershell
node .\web-demo\server.mjs
```

也可以直接双击 `web-demo/index.html`，再点击“选择 BMP”读取本地图片。直接打开 HTML 时，“加载案例 BMP”可能受到浏览器本地文件限制，请手动选择图片，或改用上面的 HTTP 地址。

`knit-renderer.js` 负责周期纱线几何、着色、荆棘高度场和 OpenGL 法线，`render-worker.js` 负责后台渲染，`render-task.js` 负责渲染调度、取消及分批回退，`app.js` 负责文件、调色板、预览及统一 JPG 编码和 DPI 写入。点击“生成高度图 + 法线图”会先生成 `fabric-height-radial.jpg`，再从同一高度场生成 `fabric-normal-opengl.jpg`。

在 `web-demo` 目录运行 `node --test regression.test.cjs resolution.test.cjs relief.test.cjs` 可检查线程故障、直接打开文件、取消、分批渲染一致性、荆棘轮廓、正片叠底、JPG 编码、DPI 及输出尺寸。

这是程序化的针织表面近似，尚未模拟真实纤维毛羽与纱线张力。全图默认每个 BMP 像素宽约 4 像素；观察上下双线圈的穿套与截面应使用独立重绘的局部视图。
